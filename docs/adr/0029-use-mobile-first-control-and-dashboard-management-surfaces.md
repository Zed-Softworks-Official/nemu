# Use mobile-first Control and dashboard Management surfaces

Nemu will make the mobile app the primary Control surface for everyday live Device and Room control and essential Device setup. The dashboard retains the same ordinary direct control as a secondary Control surface, and is the sole full Management surface for membership administration, Automations, detailed History and energy analysis, diagnostics, detailed Controller health, networking and Relay configuration, Release channel changes, backups and restores, and bulk operations. Mobile supports Home selection, separate per-Home Access Client pairing, self-revocation, leaving a Home, Device commissioning, Device renaming, Room assignment, and removal, and Room creation, renaming, and deletion. Deleting a Room on mobile or the dashboard moves every Device in it, and every Component assigned to it, to one chosen Room or to No Room and deletes it in one step. Nemu has no user-defined Group model initially; Rooms are its only control grouping. Focused mobile summaries and alerts are allowed, but dense configuration, drill-down analysis, and bulk work are not.

The first mobile delivery is a complete live-control loop: Home selection and pairing, a Room and Device list, current state, individual Capability controls, and Command feedback. When the Controller is unreachable over both LAN and Relay, mobile marks cached state stale, disables controls, and does not queue Commands for later execution. Device setup and other mobile workflows follow this slice. A lower-friction BLE Access Client-pairing flow follows the first slice; it is distinct from mobile-assisted Device commissioning. Mobile awareness is in-app only initially and does not send operating-system push notifications.

## Amended mobile scope

Amended on 2026-11-23 for the mobile redesign. Mobile Settings shows every Membership the installed Release and whether a newer one is available. Owners also get Install update and Roll back, whether the Relay is connected, and a Controller health summary; these work the same over LAN and Relay. Mobile shows or hides Owner-only actions using the Membership role the Controller reports for the current session, and Core still enforces every permission (ADR-0005, ADR-0006). Changing the Release channel, backups and restores, Membership and Invitation management, networking, Automations, diagnostics, and bulk work stay dashboard-only.
