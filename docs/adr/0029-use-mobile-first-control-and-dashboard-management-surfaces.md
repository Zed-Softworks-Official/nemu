# Use mobile-first Control and dashboard Management surfaces

Nemu will make the mobile app the primary Control surface for everyday live Device and Room control and essential Device setup. The dashboard retains the same ordinary direct control as a secondary Control surface, and is the sole full Management surface for membership administration, Automations, detailed History and energy analysis, diagnostics, Controller health, networking and Relay configuration, releases, backups and restores, and bulk operations. Mobile supports Home selection, separate per-Home Access Client pairing, self-revocation, leaving a Home, and Device commissioning, Room creation, assignment, renaming, and removal. Nemu has no user-defined Group model initially; Rooms are its only control grouping. Room deletion remains dashboard-only and requires the affected Devices to be reassigned. Focused mobile summaries and alerts are allowed, but dense configuration, drill-down analysis, and bulk work are not.

The first mobile delivery is a complete live-control loop: Home selection and pairing, a Room and Device list, current state, individual Capability controls, and Command feedback. When the Controller is unreachable over both LAN and Relay, mobile marks cached state stale, disables controls, and does not queue Commands for later execution. Device setup and other mobile workflows follow this slice. A lower-friction BLE Access Client-pairing flow follows the first slice; it is distinct from mobile-assisted Device commissioning. Mobile awareness is in-app only initially and does not send operating-system push notifications.
