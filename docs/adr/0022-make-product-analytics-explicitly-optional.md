# Make Product Analytics Explicitly Optional

Nemu needs product and reliability signals during product development, but sending them conflicts with the default privacy posture. Sentry for Core and PostHog for the web and mobile clients will therefore be disabled by default and enabled only after an explicit first-setup choice. Core reporting uses Home-level consent controlled by an Owner; web and mobile reporting use separate Account or Access Client consent so one Owner cannot consent for another person's client. Opted-in reporting uses separate pseudonymous identifiers rather than Account, Home, Access Client, or Device IDs. Strict event allowlists and boundary scrubbing prevent accidental collection. Cloud logs continue to exclude Relay envelope contents, Device identifiers, Commands, and Device state.
