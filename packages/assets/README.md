# `@nemu/assets`

Shared brand and marketing art for Nemu apps. Proprietary — see [LICENSE-ART](../../LICENSE-ART).

## Usage

```ts
import logoDark from '@nemu/assets/logos/logo-dark.png'
import favicon from '@nemu/assets/icons/favicon.ico'
import portrait from '@nemu/assets/emotes/portrait.png'
```

Layout:

- `src/logos/` — wordmarks
- `src/icons/` — favicon / app icon
- `src/emotes/` — sticker art
